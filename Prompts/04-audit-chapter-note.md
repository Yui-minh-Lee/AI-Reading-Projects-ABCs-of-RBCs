# Prompt: Audit Chapter Note

Use high reasoning.

Read `AGENTS.md` first.

Please audit and revise this note:

`ChapterNotes/[CHAPTER_NOTE_FILE]`

Use the source chapter file if needed:

`Sources/Chapters/[CHAPTER_FILE]`

Audit goals:

1. Preserve successful narrative sections.
2. Avoid rewriting the whole note unless explicitly needed.
3. Prefer targeted restructuring, compression, clarification, or expansion.
4. Ensure Main Lecture is the dominant section, roughly 65-80% of the note.
5. Reduce repetition in Compact Summary and Q&A.
6. Ensure important concepts are integrated into Main Lecture, not isolated as glossary-like material.
7. Check that important figures, tables, formulas, or visual frameworks are flagged with the required warning.
8. Check that Q&A tests understanding rather than merely repeating the summary.
9. Check whether any conclusion or transition hides non-obvious reasoning; if so, add the missing bridge in the Main Lecture.
10. Check that technical terms are explained selectively and not repeatedly.
